DTLdesktop — Guide utilisateur v1.1-18

Guide pratique pour capturer, reconnaître et restaurer une configuration de bureau Windows avec DTLdesktop.

versionv1.1-18date24 juillet 2026plateformeWindows 10 / 11runtimePython 3.10 ou supérieurinterfacefr / enlicenceMIT

Préface

Objet du guide

Ce guide explique comment utiliser DTLdesktop pour capturer, reconnaître et restaurer une configuration de bureau Windows : disposition et orientation des écrans, fond d'écran de chaque moniteur et position de chaque icône. Il couvre le mode interactif, les options en ligne de commande, la lecture des diagnostics affichés à l'écran, ainsi qu'un ensemble de scénarios courants.

Pour la description fonctionnelle de l'outil, la raison pour laquelle il a été créé et le détail de son fonctionnement interne, consultez le Manuel de référence DTLdesktop.

Audience visée

Ce guide s'adresse à toute personne qui utilise DTLdesktop au quotidien sur un poste multi-écrans : administrateurs de postes de travail, personnel de support amené à restaurer un bureau après une intervention matérielle, et mainteneurs de la suite NetDTL. Aucune connaissance de programmation n'est requise.

Rappel : qu'est-ce que DTLdesktop

DTLdesktop enregistre, sous la forme d'un profil, l'état d'un bureau Windows : disposition et orientation des écrans, fond d'écran de chaque moniteur, position de chaque icône. Il reconnaît ensuite automatiquement une configuration déjà connue, y compris après une permutation physique d'écrans, et restaure en une seule opération vérifiée l'ensemble de cet état. Ce rappel est volontairement bref ; le pourquoi et le fonctionnement interne sont développés dans le manuel de référence.

Prise en main

Lancement

DTLdesktop se lance sans argument pour ouvrir le mode interactif, décrit dans la section suivante. Lancé avec une option (par exemple --auto ou --diagnose), il exécute directement l'action correspondante puis se termine, sans afficher de menu ; c'est le mode non interactif, présenté plus loin dans ce guide.

Écran d'accueil et détection

Au lancement, DTLdesktop efface l'écran, affiche son en-tête, puis détecte la configuration d'écrans effectivement branchée à cet instant. Pour chaque moniteur, il affiche la résolution, l'orientation et, s'il s'agit de l'écran principal, la mention correspondante ; il affiche ensuite la disposition des écrans de gauche à droite.

DTLdesktop indique ensuite si cette configuration correspond à un profil déjà enregistré (Configuration sélectionnée : <nom du profil>) ou s'il s'agit d'une configuration qu'il ne reconnaît pas (Nouvelle configuration), auquel cas il propose un nom par défaut pour l'enregistrer.

Notion de profil

Un profil est l'enregistrement complet d'une configuration de bureau : la disposition des écrans, le fond d'écran de chacun pour ses deux orientations possibles, et la position de chaque icône du bureau. Chaque profil est un sous-dossier du dossier Desktop, situé à côté de l'application.

Nommage des profils

DTLdesktop attribue lui-même le nom d'un profil ; il n'existe pas d'option pour saisir un nom au clavier. Ce nom par défaut décrit le nombre d'écrans et leur orientation (par exemple SingleLandscape, DualPortrait, TripleMixed). Lorsqu'une configuration correspond exactement à un profil déjà enregistré, DTLdesktop réutilise le nom de ce profil.

À savoir : deux configurations physiquement différentes mais comportant le même nombre d'écrans dans les mêmes orientations (par exemple un poste fixe et un poste portable disposant chacun de deux écrans paysage) reçoivent le même nom par défaut. Pour les distinguer durablement, renommez le sous-dossier correspondant dans Desktop depuis l'Explorateur Windows après l'avoir enregistré une première fois ; voir le scénario Distinguer deux configurations similaires.

Reconnaissance automatique

À chaque lancement, DTLdesktop compare la configuration détectée aux profils enregistrés. Une correspondance exacte est reconnue même si Windows a renommé les écrans depuis l'enregistrement du profil, par exemple après une permutation physique de deux moniteurs. Si aucune correspondance exacte n'existe mais qu'un profil compatible est trouvé, DTLdesktop le retient également. En l'absence de toute correspondance, il affiche Nouvelle configuration.

Mode interactif

Vue du menu

Une fois la configuration détectée affichée, DTLdesktop propose le menu suivant, accessible en tapant la lettre correspondante puis en validant :

[A] Appliquer un profil [S] Sauvegarder le profil actuel [R] Restaurer les icônes [D] Diagnostiquer [T] Tester [C] Comparer [F] Choisir les fonds [Q] Quitter

Le menu reste affiché après chaque action, ce qui permet d'enchaîner plusieurs opérations sans relancer l'outil.

Sauvegarder le profil actuel (S)

Enregistre l'état actuel du bureau — écrans, icônes et fonds d'écran — sous le nom de profil actuellement sélectionné (celui reconnu, ou celui proposé par défaut pour une nouvelle configuration). Si un profil de ce nom existe déjà, il est remplacé par l'état courant. DTLdesktop confirme le nombre d'icônes et d'écrans enregistrés.

Appliquer un profil (A)

Propose la liste des profils enregistrés, demande d'en choisir un par son numéro, puis indique combien d'écrans verront leur orientation ou leur disposition modifiée par cette application. Après confirmation (O/N), DTLdesktop modifie dans l'ordre l'orientation et la résolution des écrans, les fonds d'écran, puis la position des icônes, et vérifie que le résultat correspond au profil. En cas d'échec de cette vérification, DTLdesktop tente automatiquement de revenir à l'état qui précédait l'opération et affiche le message d'erreur correspondant.

Attention : cette action peut faire changer l'orientation ou la résolution d'un ou plusieurs écrans. Le nombre d'écrans concernés est annoncé avant la confirmation ; relisez-le avant de valider.

Restaurer les icônes seules (R)

Propose la liste des profils enregistrés, affiche un aperçu de ce qui serait modifié (icônes déplacées, absentes ou nouvelles) sans rien appliquer, puis demande confirmation. Après confirmation, seules les positions des icônes du bureau sont restaurées à partir du profil choisi ; la disposition des écrans et les fonds d'écran ne sont pas modifiés. DTLdesktop indique le nombre d'icônes restaurées et signale celles du profil qui sont introuvables sur le bureau actuel.

Diagnostiquer (D)

Affiche la configuration d'écrans détectée. Si elle correspond à un profil connu, DTLdesktop affiche également le diagnostic des fonds d'écran de ce profil, écran par écran (voir Lire le diagnostic des fonds d'écran). Si un ou plusieurs fonds d'écran sont incohérents, DTLdesktop propose de les corriger immédiatement ; seuls les fonds d'écran sont alors modifiés, ni les icônes ni la disposition des écrans. Si la configuration n'est pas reconnue, DTLdesktop indique qu'il s'agit d'une nouvelle configuration et invite à l'enregistrer avec S.

Choisir les fonds d'écran (F)

Ouvre, pour chaque écran détecté, le sélecteur de fichiers de Windows afin de choisir une image de fond d'écran ; le dossier d'image ouvert par défaut est celui utilisé lors de la dernière sélection. Annuler la sélection pour un écran conserve son fond actuel. Les fonds sont toujours appliqués en mode « Remplir », sans choix supplémentaire. Après une rotation, DTLdesktop réapplique chaque fond, même si son chemin n'a pas changé, afin que Windows ne conserve pas l'image calculée pour l'orientation précédente.

À savoir : choisir un fond d'écran avec F le rend actif immédiatement mais ne l'enregistre pas dans un profil. Pour conserver ce choix, appuyez ensuite sur S. Le fond enregistré est associé à l'orientation courante de l'écran (paysage ou portrait) ; l'autre orientation garde le fond qui lui était déjà associé.

Tester et comparer (T / C)

Ces deux lettres déclenchent la même action : proposer la liste des profils enregistrés, puis afficher, pour le profil choisi, une comparaison avec l'état actuel du bureau — écrans identiques ou différents, nombre d'icônes déplacées, absentes ou nouvelles, nombre de fonds d'écran incohérents. Aucune modification n'est appliquée ; cette action sert uniquement à examiner un écart avant de décider d'une correction avec A ou R.

Quitter (Q)

Ferme DTLdesktop sans effectuer de dernière action.

Mode non interactif

Vue d'ensemble

Chaque option ci-dessous exécute une seule action puis termine DTLdesktop, sans afficher le menu. Ce mode est destiné à une intégration à un script de démarrage, une tâche planifiée, ou tout appel automatisé.

--auto

Restaure automatiquement le profil reconnu pour la configuration détectée — équivalent à choisir A sur le profil reconnu, sans confirmation. Si aucun profil compatible n'est trouvé, DTLdesktop l'indique et ne modifie rien.

--save

Enregistre la configuration détectée sous le nom reconnu ou proposé par défaut, sans demander de confirmation ni de nom — équivalent à S en mode interactif.

--apply <profil>

Applique le profil désigné : orientation, résolution, fonds d'écran et icônes — équivalent à A suivi de la sélection de ce profil et de la confirmation.

--restore <profil>

Restaure uniquement les icônes du profil désigné, sans toucher à la disposition des écrans ni aux fonds d'écran — équivalent à R suivi de la sélection de ce profil et de la confirmation.

--test <profil>

Affiche la comparaison entre l'état actuel du bureau et le profil désigné, sans rien modifier — équivalent à T ou C.

--diagnose

Affiche la configuration détectée et, si elle correspond à un profil connu, le diagnostic de ses fonds d'écran — équivalent à D, sans proposer de correction.

--version affiche uniquement le numéro de version de DTLdesktop.

Codes de sortie

CodeSignification
0Action effectuée sans erreur.
1Une erreur a interrompu l'action (voir Messages d'erreur courants).

Scénarios courants

Premier profil sur un poste

  1. Branchez et disposez les écrans comme souhaité, réglez leur orientation dans Windows si nécessaire.
  2. Lancez DTLdesktop. La configuration est détectée et annoncée comme nouvelle.
  3. Si besoin, choisissez le fond d'écran de chaque moniteur avec F.
  4. Enregistrez avec S. Le profil est créé sous le nom proposé par défaut.

Fond d'écran différent selon l'orientation d'un écran

Pour un écran que vous faites parfois pivoter entre paysage et portrait, DTLdesktop peut appliquer automatiquement un fond différent selon l'orientation effective.

  1. Orientez l'écran en paysage, choisissez son fond avec F, puis enregistrez avec S.
  2. Faites pivoter l'écran en portrait. DTLdesktop détecte la nouvelle orientation au lancement suivant.
  3. Choisissez le fond correspondant à l'orientation portrait avec F, puis enregistrez à nouveau avec S.

Les deux fonds sont désormais conservés dans le même profil ; chacun est réappliqué automatiquement selon l'orientation détectée lors d'une restauration.

Restaurer après une permutation physique de deux écrans

Après avoir physiquement échangé la place de deux moniteurs, Windows peut inverser leurs noms de périphérique et redistribuer les icônes.

  1. Lancez DTLdesktop. Grâce à la signature géométrique du profil, la configuration reste reconnue malgré le changement de nommage.
  2. Appuyez sur A, sélectionnez le profil reconnu, confirmez.
  3. DTLdesktop remet en place l'orientation de chaque écran, ses fonds d'écran et la position de ses icônes.

Corriger un fond d'écran isolé sans tout réappliquer

  1. Appuyez sur D. DTLdesktop affiche, écran par écran, si le fond observé correspond au fond attendu par le profil reconnu.
  2. Si un écart est signalé, répondez O à l'invite de correction. Seuls les fonds d'écran non conformes sont corrigés.

Cette action ne touche ni à la disposition des écrans ni à la position des icônes.

Restauration automatique à l'ouverture de session

L'option --auto est destinée à un appel automatisé, par exemple depuis une tâche exécutée à l'ouverture de session ou depuis un script de démarrage de poste. Elle restaure sans confirmation le profil reconnu pour la configuration présente à ce moment, ce qui permet de retrouver disposition, fonds d'écran et icônes sans intervention manuelle.

Distinguer deux configurations similaires

Deux dispositions physiquement différentes mais de même type (même nombre d'écrans, mêmes orientations) reçoivent le même nom de profil par défaut. Pour les conserver séparément :

  1. Enregistrez la première configuration avec S.
  2. Dans l'Explorateur Windows, renommez le sous-dossier correspondant sous Desktop pour lui donner un nom distinctif.
  3. Installez-vous dans la seconde configuration, puis enregistrez-la avec S : elle crée un nouveau profil sous le nom par défaut, sans écraser le profil renommé.

Lire le diagnostic des fonds d'écran

Pour chaque écran, le diagnostic affiché par D indique sa résolution, son orientation, le fond d'écran actuellement observé, puis une conclusion :

  • ✓ conforme : le fond observé correspond au fond attendu par le profil pour l'orientation actuelle de l'écran.
  • ⚠ fond d'écran incohérent : le fond observé diffère du fond attendu ; les deux noms de fichier sont affichés pour comparaison.

Profils

Un sous-dossier par profil enregistré, contenant monitors.json, icons.json et wallpaper.json.

Desktop/settings.json

Profil actif et dernier dossier d'image utilisé par le sélecteur de fond d'écran (F).
